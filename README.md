## Project Overview
The **Network Intrusion Detection System (NIDS)** is a Machine Learning-based project designed to detect malicious activities and unauthorized access in a network.

This system analyzes network traffic data and classifies it as **normal or attack**, helping improve cybersecurity and prevent potential threats.

---

## Dataset Used
- Network traffic dataset  
- Features include:
  - Protocol type  
  - Service  
  - Source & destination bytes  
  - Flag status  
- Data preprocessing steps:
  - Handling missing values  
  - Encoding categorical features  
  - Feature scaling  

---

## Project Scope
- Analyze network traffic patterns  
- Detect anomalies and attacks  
- Build a classification model  
- Improve cybersecurity monitoring
